# Andrés Piedra — sitio personal actualizado

Sitio estático HTML, CSS y JavaScript. No requiere Angular ni WordPress.

## Ejecutar localmente
Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.

## Publicar en Netlify
Arrastra el contenido de esta carpeta a Netlify Drop o conecta el repositorio Git. La carpeta de publicación es la raíz del proyecto.
